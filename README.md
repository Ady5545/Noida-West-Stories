# Noida West Stories 🎮

Browser-first 3D open-world game prototype inspired by Greater Noida West.

## Prototype 0.2
- Third-person camera by default
- First-person toggle (V)
- Mouse-look
- On-foot movement (WASD + sprint)
- Enter/exit Cityrunner S1 (E)
- Arcade car physics
- **Real OpenStreetMap road network centered on Greater Noida West**
- Pedestrian NPCs
- Traffic positioned from live road geometry when map data loads
- Day/night clock
- Static-browser architecture using Three.js from a pinned CDN
- No Unity and no local install/build step

## Roadmap
1. Camera collision and better character controller
2. Vehicle collisions, suspension, wheel steering and stronger physics
3. Authored Noida West districts and landmarks
4. Traffic AI and richer pedestrian routines
5. Homes, garages, shops, missions, economy and saves
6. Radio, original ambient audio, weather and world events
7. Map/minimap and mobile/tablet controls

Real-world geography is treated as inspiration during prototyping. Any future real map-data integration should preserve its source and licensing/attribution requirements.
